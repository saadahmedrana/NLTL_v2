# Benchmark vocabulary workspace

This folder is organized around the locked Stage 2 vocabulary and its LLM context layer.

## Current active material

- `STAGE2/` — current Stage 2 vocabulary, registry, profiles, JSON-LD context, ontology serializations, structural QA shapes, reports, and validation evidence.
- `PIPELINE_CONTEXT/` — current code and machine-readable assets for creating requirement-scoped LLM context packs.
- `../benchmark_vocabulary_stage2_LOCK-2026-08-12-R1.xlsx` — locked workbook in the project root.
- `../benchmark_vocabulary_stage2_LOCK-2026-08-12-R1.lock.json` — hash and artifact lock record.
- `../INPUTS/benchmark_vocabulary_stage2_LOCK-2026-08-12-R1.xlsx` — active pipeline-input copy.
