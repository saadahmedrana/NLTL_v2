# NLTL benchmark vocabulary - Stage 2 R2

R2 is a non-overwriting revision of R1 for the IMO-057 pilot-discovered node-model gap. It retires the active string-valued `containingCompartment` term, introduces `hasContainingCompartment`, `compartment`, `emergencyFirePump`, `waterMistPump`, and `waterSprayPump`, and preserves the verified regulatory wording and all R1 artifacts.
