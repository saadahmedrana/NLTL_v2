# R4 generated-shape RDF confirmation

This development-only suite evaluates the actual pipeline-generated R14 shapes for I2-005 and IMO-086. The RDF graphs were authored independently from the generated SHACL using the cited regulatory clauses and the R14 canonical vocabulary. They are not supplied to the generator.

The seven variants cover the exact 7-degree boundary and unit discipline for I2-005, plus minimum count, per-device power connectivity, and independence for IMO-086. File hashes in `evaluation_manifest.json` prevent silent alteration of either shapes or RDF inputs.
