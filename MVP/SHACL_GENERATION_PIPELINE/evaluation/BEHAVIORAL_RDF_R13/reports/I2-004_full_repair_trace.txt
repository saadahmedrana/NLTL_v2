Why the FULL SPARQL is wrong
----------------------------
The FULL query reports a violation only when both of these are true:

  FILTER NOT EXISTS { ... FILTER (?caseValue > ?duiValue) }
  FILTER NOT EXISTS { ... FILTER (?matchingValue = ?duiValue) }

This flags a selected value that is at least as large as every case but matches no
case (for example, a value above the maximum). It does not flag a selected value
below the maximum: when a greater case exists, the first FILTER NOT EXISTS is false,
so the query returns no violation. That is exactly why F01 (selected 12, represented
12 and 15) incorrectly conforms.
