NLTL manual audit setup

1. Create this folder in the local repository:
MVP/SHACL_GENERATION_PIPELINE/evaluation/manual_audit/AUDIT_20260915/

2. Place NLTL_Manual_Audit.xlsx, audit_selection.json and CODEX_PREPARE_AUDIT.txt there.

3. Paste the entire CODEX_PREPARE_AUDIT.txt into local Codex. It prepares the text packets and fills any missing local metadata. It must not launch generation or behavioural experiments.

4. Codex will create 27 batch TXT files. Send BATCH_01.txt and the current working workbook to ChatGPT. We can review the source interpretation, code and two selected cases, then record draft grades and your agreed decisions. Continue batch by batch.

5. Use V2, NoSemantic and SingleShot for separate code grading. Use CaseReview for a shared audit of the original source/fixture/label. Filter Selected for review to 1 to see the 536 sampled scenarios. Definitions and literature links are in Rubric; workflow details are in Guide.

6. Results shows the original RUN_01 comparison and a separate live label-only recalculation for the three architectures. Graph edits require an offline rerun; manual code grades do not overwrite RDF results.

V2 means accepted outputs plus all 25 preserved rejected iteration-4 candidates. No manual grades or label corrections have been assigned yet.

The initial package contains RUN_01 prefills because those are the evaluated records supplied. The Codex prompt inventories other compatible, completed RDF-evaluated runs locally and samples one specimen per architecture/requirement reproducibly. The chosen two RDF case IDs and batch memberships stay fixed. Original RUN_01 metrics remain separate even when a specimen comes from another run.

The criterion content is grounded in W3C SHACL, Barr et al. (2015) on the test oracle problem, and Chen et al. (2021) on functional code evaluation. The maritime questions, 0-2 anchors and equal weights are explicitly project-designed; they are not a validated published grading scale.

Reviewing two cases per requirement does not validate every branch or all 2,186 cases. If we stop early, report the reviewed sample and its selection method; targeted triage does not justify a population accuracy claim.

Keep row order in CaseReview, RawResults and RequirementScores unchanged. Use filters rather than sorting or deleting rows on these linked evidence sheets.
