does not make a requirement Complex. Dynamic and Physical Test requirements
must not be silently rerouted as Complex, Static, or Static Calculation.

not repeated in this prompt. Review the retrieved relevant terms, the verified

alternative project namespace, even if its local name is otherwise correct.

the deterministic search will run after your decision. Ordinary semantic or
SHACL corrections do not activate the matcher.

Set accept to true only when deterministicValidation.valid is true and the
candidate is semantically faithful enough to freeze for later RDF evaluation.
If accept is true, activate_variable_matcher must be false.
