We need to fix the SPARQL syntax error. In SHACL-SPARQL select queries, the structure is SELECT ?this ... WHERE { ... } GROUP BY ... HAVING ... or you can use SELECT ... WHERE ... FILTER after the WHERE but the error arises because after WHERE clause they placed FILTER after closing brace but also using BIND inside WHERE then closing brace and then FILTER outside. In SPARQL, FILTER must be inside WHERE clause, before the closing brace, or you can have another clause after but not after closing brace. So move FILTER inside the WHERE before the closing brace.

Alternatively we can compute MAX via aggregation using GROUP BY. The current query uses BIND (MAX(?caseValue) AS ?maxCaseVal) which is not allowed; aggregate functions must be used in SELECT or HAVING, not BIND. So better to use SELECT (MAX(?caseValue) AS ?maxCaseVal) ?shipValue where GROUP BY ?shipValue. Simpler: SELECT $this ?shipValue (MAX(?caseValue) AS ?maxCaseVal) WHERE { ... } GROUP BY $this ?shipValue HAVING (?shipValue != ?maxCaseVal)
