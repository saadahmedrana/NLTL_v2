# Blinded manual audit package

`BATCH_01.zip` is the uploadable blinded review packet. It contains ten requirements, all 80 required artifact slots, frozen RDF fixtures, expected labels, ontology context, and the scoring workbook.

`PRIVATE/BLINDING_KEY.csv` is deliberately outside the ZIP. Keep it private until scoring and adjudication are complete. No generation or RDF evaluation is performed by this packaging workflow.
